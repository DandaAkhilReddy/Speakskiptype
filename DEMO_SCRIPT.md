# Demo Script for SpeakSkipType

Use this script when recording a video demo or presenting the tool live.

---

## VIDEO DEMO SCRIPT (60 seconds)

---

### [0-10 seconds] - Hook

**Say:** "Hey developers! Let me show you something that's going to change how you work in the terminal."

**Show:** Your terminal, maybe with some code visible

---

### [10-25 seconds] - The Problem

**Say:** "So here's what we've ALL been doing. We open ChatGPT... click the voice button... speak... wait for transcription... copy it... switch back to terminal... and paste. That's seven steps. Every. Single. Time."

**Show:** Quick cuts of you doing each step (or just describe with hand gestures)

---

### [25-45 seconds] - The Solution Demo

**Say:** "I built a tool that does this in THREE keystrokes. Watch."

**Show:**
1. Terminal with SpeakSkipType running
2. Cursor positioned in another terminal/text field

**Say:** "Ctrl+R to start recording..."

**Show:** Press Ctrl+R, see [REC] indicator

**Say:** "Git commit dash m fix authentication bug"

**Show:** The partial text appearing as you speak

**Say:** "Ctrl+S to stop..."

**Show:** Press Ctrl+S, watch text auto-type at cursor

**Say:** "And BOOM - it auto-types directly into my terminal. No copy-paste. No switching windows."

---

### [45-55 seconds] - Key Benefits

**Say:** "And the best part? It's completely free. No API keys. Runs 100% locally on your laptop. Works offline. Any terminal - Windows, Linux, Mac."

**Show:** Maybe flash the GitHub page or README

---

### [55-60 seconds] - Call to Action

**Say:** "Link to the GitHub repo is in the description. Clone it, install it, and start speaking directly into your terminal. Drop a comment if this saves you time!"

**Show:** GitHub URL on screen

## SCREEN RECORDING TIPS

---

1. **Use a clean terminal** - No clutter, maybe a dark theme
2. **Increase font size** - At least 16pt for visibility
3. **Show the hotkeys** - Use a key overlay tool to show Ctrl+R, Ctrl+S
4. **Speak clearly** - Enunciate for the demo
5. **Short commands** - Use simple examples that type quickly
6. **Position matters** - Show the cursor clearly before typing

## OBJECTION HANDLERS

---

**"Why not just use Mac/Windows dictation?"**
- Those don't work in all terminals
- They often add to wrong window
- SpeakSkipType types exactly at your cursor position

**"Is it accurate?"**
- 95%+ accuracy with clear speech
- Uses the same tech as Google/Amazon for offline
- You can always edit after - still faster than typing

**"Does it work offline?"**
- Yes! After first setup (downloads 40MB model)
- 100% local processing
- No data sent anywhere
